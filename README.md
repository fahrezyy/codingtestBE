# Inventflow - Product Management System (PHP & SQLite)

Aplikasi Back-End API sekaligus Web Dashboard profesional untuk pengelolaan produk inventaris. Dibangun menggunakan **PHP Native**, **SQLite** sebagai basis data lokal yang ringan, dan **Tailwind CSS** untuk antarmuka pengguna yang bersih dan modern.

---

## 🛠️ Bahasa Pemrograman & Tools
* **Bahasa:** PHP (>= 8.0)
* **Database:** SQLite (`database.sqlite`)
* **Styling & UI:** Tailwind CSS & Font Awesome
* **Tools Testing API:** Postman / cURL / Browser

---

## ✨ Fitur Utama
1. **Web Dashboard Interaktif:** Tampilan antarmuka bergaya SaaS modern untuk mengelola produk secara visual.
2. **CRUD Produk:** Tambah, lihat, ubah, dan hapus data produk dengan mudah.
3. **Pencarian & Filter:** Cari produk berdasarkan nama/kategori dan filter berdasarkan status ketersediaan (*tersedia* / *habis*).
4. **Statistik Real-Time:** Kartu ringkasan total produk, stok tersedia, dan stok habis.
5. **Autentikasi Token Statis:** Pengamanan endpoint dengan simulasi *Bearer Token*.
6. **Validasi Input & Toast Notification:** Validasi ketat pada form dan notifikasi interaktif yang responsif.
